# Third-Party Runtime Dependencies

## Python runtime dependencies

The required Python packages are listed in `requirements.txt` and installed by `scripts/setup_env.sh`.

## External binaries

Zedd-Satellite depends on external capture/decoder tools such as `rtl_fm`, `sox`, `wxtoimg`, `noaa-apt`, `meteor-demod`, and `medet`.

## Commercial suitability

This repository does not replace the need for a legal review of third-party decoder licenses before commercial shipment. Verify the redistribution and field-use terms for each external binary in your product bill of materials before release.
