# Support

## Supported scope

The repository supports the Raspberry Pi based ground-station deployment documented in the README and deployment assets under `deploy/`.

## When requesting help

Include:

- the deployed version/tag
- Raspberry Pi model and OS version
- relevant `logs/zedd-satellite.log` excerpts
- whether the issue affects capture, decoding, frontend access, or hardware health

## Out of scope

- custom decoder forks
- unsupported SDR hardware
- direct internet exposure of the dashboard without the documented reverse proxy
